# ExpenseTracker Backend

REST API for personal finance management.
Built with Spring Boot and JWT-based authentication.

## Features
- User registration and login
- JWT authentication (Bearer Token)
- Protected endpoints
- Expense and income management per user
- Centralized error handling
- CORS configuration for React frontend

## Tech Stack
- Java 17
- Spring Boot
- Spring Security
- JPA / Hibernate
- Maven

## Getting Started

### Prerequisites
- Java 17+
- Maven
